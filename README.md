# Swag Labs (SauceDemo) - Test Case Documentation & Jira Management

##  Project Overview
This project demonstrates a comprehensive Quality Assurance (QA) testing suite and Agile workflow management for the **Swag Labs (SauceDemo)** e-commerce application using **Atlassian Jira**.

The project covers End-to-End (E2E) purchasing flows, user authentication scenarios, cart management, sorting, and side-navigation handling.

---

##  Tools & Methodologies
* **Test Management Tool:** Atlassian Jira
* **Agile Framework:** Scrum / Kanban Board
* **Testing Types:** Manual Testing, E2E Testing, Functional Testing, Negative Validation
* **Test Design Techniques:** Equivalence Partitioning, Use Case Testing

---

## Test Scenarios Covered

### 1. End-to-End (E2E) Purchase Flow
* **SAM1-6:** Buy Product - Check The E2E successful buy product flow.
* **SAM1-12:** Buy Product - Check E2E buy product flow after removing a product from cart.
* **SAM1-13:** Buy Product - Check E2E buy product flow after sorting products by price.
* **SAM1-14:** Buy Product - Check E2E buy product flow with missing checkout information (Negative).
* **SAM1-15:** Buy Product - Check E2E buy product flow after cancelling checkout.
* **SAM1-16:** Buy Product - Check E2E buy product flow using performance glitch user.

### 2. User Authentication
* **SAM1-17:** Login - Check all user authentication scenarios (Valid user, Locked-out user, Empty credentials).

### 3. Side Navigation & App State
* **SAM1-22:** Navigation - Check side menu functionality and app reset.
* **SAM1-23:** Navigation - Check successful logout using side menu.
* **SAM1-24:** Navigation - Check Reset App State option clears cart.
